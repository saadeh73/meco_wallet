## 🚀 **النظرة العامة**

**MECO Wallet** ليست مجرد محفظة رقمية... بل هي **بوابتك الكاملة إلى الاقتصاد الرقمي اللامركزي**!

في عالمٍ تزدحم فيه المحافظ الرقمية، نطرح سؤالاً جوهرياً: **ما الذي يجعل MECO مختلفة؟**

✨ **الإجابة تكمن في رؤيتنا:**
- 🎯 نحن لا نكتفي بتخزين العملات؛ بل نصنع **مركز تحكم شخصي** يمنحك الحرية الكاملة
- 💪 إدارة كاملة لأموالك بدون وسيط
- 🔐 أمان عالي المستوى مع تشفير قوي
- 🌍 تطبيق لامركزي حقيقي يعمل بدون خوادم وسيطة

**MECO Wallet انطلقت بقوة وتعمل اليوم بكفاءة عالية لتثبت أنها أكثر من مجرد أداة إرسال واستقبال.**

## 🧱 **التقنيات المستخدمة (Tech Stack)**

- **React Native & Expo** (SDK 54) - لبناء تطبيق متعدد المنصات

- **expo-secure-store** - تخزين المفاتيح الخاصة بشكل آمن

- **WalletConnect v2 Core** - ربط آمن مع تطبيقات Web3

- **Ankr RPC** - خادم بديل احتياطي للاتصالات

### 💱 **الأسعار والتبادل**
- **Jupiter API** - مزود السيولة الأمثل للتبادلات
- **CoinGecko API** - أسعار حقيقية ومحدّثة للعملات

### 🌍 **تعدد اللغات والترجمة**
- **i18next** - دعم كامل لتعدد اللغات (العربية والإنجليزية وأخرى)

### 📊 **الواجهة والمكتبات الإضافية**

## 🔐 **الأمان والخصوصية (Security)**

### 🛡️ **معايير الأمان العالية**

✅ **المفاتيح الخاصة (Private Keys)**
- مشفرة بمعيار عالي ومخزنة محلياً باستخدام `expo-secure-store`
- **لا تغادر جهاز المستخدم أبداً** - فقط أنت تملك مفاتيحك
- لا توجد نسخة احتياطية على خوادم بعيدة

✅ **المصادقة (Authentication)**
- دعم كامل للمصادقة البيومترية (بصمة الإصبع / Face ID)
- حماية إضافية لعبارة الاسترداد (Seed Phrase)
- رمز PIN اختياري إضافي

✅ **اللامركزية الحقيقية**
- **لا توجد خوادم وسيطة** تمتلك صلاحية الوصول لأموالك
- تحكم كامل وحصري في محفظتك
- لا تعتمد على جهات خارجية لتخزين الأموال

✅ **الشفافية والثقة**
- كود **مفتوح المصدر** (Open Source) على GitHub
- يمكن لأي شخص مراجعة الكود والتحقق من الأمان
- معايير ثقة مجتمعية عالية

### ⚠️ **نصائح الأمان للمستخدمين**

1. **احفظ كلمات الاسترداد** بمكان آمن وبعيد عن الإنترنت
2. **لا تشارك مفاتيحك الخاصة** مع أي شخص أو موقع
3. **تفعيل المصادقة البيومترية** لحماية إضافية
4. **تحديث التطبيق** بانتظام للحصول على أحدث تحديثات الأمان

## 📥 **المتطلبات والتثبيت**

### ✅ **متطلبات التشغيل**

**للمستخدمين النهائيين:**
- 📱 هاتف ذكي بنظام **Android 8.0** أو أحدث
- 💾 مساحة تخزين: **100 MB** على الأقل
- 🌐 اتصال إنترنت مستقر
- 🔋 عمر بطارية معقول

**للمطورين:**
- 💻 Node.js v18+ و npm أو yarn
- 🔧 Expo CLI مثبت عالمياً
- 🎯 Android Studio (اختياري، للاختبار المتقدم)
- 📝 محرر نصوص: VS Code أو أي محرر تفضله

### 🚀 **خطوات التثبيت للمطورين**

#### 1️⃣ **استنساخ المستودع**
```bash
git clone https://github.com/MonyCoin/meco_wallet.git
cd meco_wallet
```

#### 2️⃣ **تثبيت المتعلقات**
```bash
npm install
# أو
yarn install
```

#### 3️⃣ **تثبيت Expo CLI** (إن لم يكن مثبتاً)
```bash
npm install -g expo-cli
```

#### 4️⃣ **بدء تشغيل التطبيق في بيئة التطوير**
```bash
expo start
```

#### 5️⃣ **الاختبار على جهازك**
- اختر **a** لتشغيل محاكي Android
- أو امسح رمز QR بتطبيق Expo Go على هاتفك

#### 6️⃣ **بناء ملف APK للإنتاج**
```bash
eas build --platform android --build-profile production
```

### 📋 **متغيرات البيئة (.env)**

أنشئ ملف `.env` في جذر المشروع:

```env
# Solana Network
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
HELIUS_API_KEY=your_helius_key_here
ANKR_API_KEY=your_ankr_key_here

# Jupiter API
JUPITER_API_KEY=your_jupiter_key

# WalletConnect
WALLETCONNECT_PROJECT_ID=your_walletconnect_project_id

# CoinGecko API
COINGECKO_API_KEY=your_coingecko_key
```

## 💡 **دليل الاستخدام**

### 🆕 **إنشاء محفظة جديدة**

1. افتح التطبيق واختر **"إنشاء محفظة جديدة"**
2. اقرأ التحذيرات الأمنية بعناية واضغط **متابعة**
3. ستظهر لك **12 كلمة استرجاع** - احفظها في مكان آمن!
4. تأكد من كلمات الاسترجاع بإعادة إدخالها
5. حدد كلمة مرور قوية لحماية محفظتك

### 📤 **إرسال عملات**

1. اضغط على **"إرسال"** من الشاشة الرئيسية
2. أدخل **عنوان المحفظة** أو امسح رمز QR
3. أدخل **المبلغ** الذي تريد إرساله
4. راجع الرسوم والتفاصيل
5. اضغط **تأكيد وإرسال**
6. قد تطلب عملية المصادقة البيومترية

### 📥 **استقبال عملات**

1. اضغط على **"استقبال"** من الشاشة الرئيسية
2. سيظهر **عنوان محفظتك** ورمز QR
3. شارك العنوان أو رمز QR مع المرسل
4. المعاملة ستظهر في سجل المعاملات بعد التأكيد

### 🔄 **تبديل العملات (Swap)**

1. اضغط على **"تبديل"** من القائمة الرئيسية
2. اختر العملة التي تريد **إرسالها**
3. اختر العملة التي تريد **استقبالها**
4. أدخل المبلغ وسترى **السعر المرجعي**
5. اضغط **تأكيد التبديل** وأكمل المصادقة

### ⚡ **تخزين العملات (Staking)**

1. اذهب إلى قسم **"التخزين"** (Staking)
2. اختر **المبلغ** الذي تريد تخزينه
3. اختر **مدة التخزين**: مرن أو مقفل (30/60 يوم)
4. ستكسب **عوائد يومية** تلقائياً
5. يمكنك سحب أموالك في أي وقت (للخطط المرنة)
